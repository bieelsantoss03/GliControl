# GliControl 🩸

Seu diário inteligente de glicemia.

## 📋 Sobre o projeto

O GliControl é uma aplicação web desenvolvida para registrar e acompanhar medições de glicemia de forma simples e organizada.

O projeto foi desenvolvido como parte do meu aprendizado em desenvolvimento web, utilizando tecnologias fundamentais do front-end.

## 🚀 Funcionalidades atuais

- Cadastro de medições de glicemia
- Registro do momento da medição
- Campo para observações
- Histórico de medições
- Cálculo da média de glicemia
- Identificação do maior valor registrado
- Identificação do menor valor registrado
- Contagem de registros
- Edição de registros
- Exclusão de registros
- Persistência dos dados utilizando LocalStorage

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub

## 📌 Status do projeto

🚧 Em desenvolvimento.

Novas funcionalidades serão adicionadas progressivamente, incluindo pesquisa e filtros de registros, dashboard e visualizações gráficas.
